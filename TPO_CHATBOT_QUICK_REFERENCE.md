# 🚀 TPO Chatbot Quick Reference Card

## View Individual Student Details

```
Query: "View student [name]"
Example: "View student John" or "Show student profile - gaurav"
Result: Complete student profile with academic & professional info
```

---

## Filter Students by CGPA

```
Query: "Show students with CGPA > [number]"
Example: "Filter students CGPA > 8" or "Students with CGPA >= 8.5"
Result: Table of students meeting CGPA requirement (sorted by CGPA)
```

---

## Filter Students by Branch

```
Query: "Show students from [branch]"
Example: "Filter students by CSE" or "List ECE branch students"
Branches: CSE, ECE, ME, Civil, Electrical, Electronics, IT
Result: All students in specified branch with CGPA
```

---

## Filter by Backlog Status

```
Query: "Show students with no backlog"
Query: "Show students with backlogs"
Example: "Filter clean records" or "Students without active backlogs"
Result: List of students with/without backlogs
```

---

## View Top Performers

```
Query: "Show top [number] students"
Example: "Show top 10 students" or "Top 5 performers"
Result: Ranked list with CGPA (default: 10)
```

---

## Analytics Dashboard

```
Query: "Analytics overview" or "Student statistics"
Result: Dashboard with total students, average CGPA, branch distribution, etc.
```

---

## ⏱️ Quick Command Guide

| Goal | Command |
|------|---------|
| Get specific student details | View student [name] |
| Find high-CGPA students | Show CGPA > 8.5 |
| Get CSE branch students | Filter by CSE |
| Find eligible candidates | Students with no backlog |
| Get best performers | Top 10 students |
| See overall stats | Analytics overview |

---

## 🎯 Use Cases

**Pre-Interview Selection:**
"View student John" → See full profile + skills → Make decision

**Batch Recruitment:**
"Show CGPA > 8" → Get eligible students → Filter by "CSE" → Generate list

**Eligibility Check:**
"Students with no backlog" → Get clean records → Filter by branch → Count eligible

**Performance Analysis:**
"Analytics overview" → See trends → Top students → Branch distribution

- ✓ You must be logged in as Admin/TPO
- ✓ Queries are case-insensitive
- ✓ You can try different phrasings
